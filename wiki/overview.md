# Social Network Agent — Overview

This project is an autonomous social-media management agent for
[ADAMA](entities/adama.md), a Jewish youth community serving young
Russian-speaking new immigrants in Israel.

The current phase is repository research only. The selected engineering base
is `langchain-ai/social-media-agent`; implementation is intentionally paused
until the operator confirms the [repository decision](concepts/repository-selection.md).
